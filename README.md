## 🚀 Featured Projects

### 📱 [Project Name]: Flutter + Supabase attendance & payments app
A full-stack mobile app with biometric attendance, UPI payments, AI assistance and automated outreach.

- **Biometric attendance:** a Python 3 local ADMS HTTP bridge connects **eSSL & ZKTeco** scanners, forwarding punches to a **Deno/TypeScript edge webhook** (`biometric_webhook.ts`)
- **Secure backend:** **Supabase (PostgreSQL)** with **Row-Level Security** across **14 relational tables**, defined in `schema.sql`
- **AI features:** **Google Gemini API** via `google_generative_ai`
- **Payments:** native Indian **UPI intent** launcher (`upi://pay`)
- **Outreach:** one-tap calling (`tel:`) and **WhatsApp** (`wa.me`) via `url_launcher`
- **Notifications:** **Firebase Cloud Messaging** + `flutter_local_notifications`
- **Receipts:** PDF generation and printing with `pdf` & `printing`
- **QR / scanning:** `mobile_scanner` and `qr_flutter`
- **Quality:** unit, widget and **security regression tests** (`security_regression_test.dart`), linted with `flutter_lints`

`Flutter` `Dart` `Riverpod` `go_router` `Supabase` `Deno` `Python` `Gemini` `FCM`
